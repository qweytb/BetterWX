# BetterWX
<img width="400" src="https://github.com/user-attachments/assets/4bdfb590-d913-4543-b54c-347f6b1d14e7" />

某补丁工具

支持平台：Windows x64<br>
支持版本：**4.1.15.50**

## 功能

- 自动点击登录
- 保留登录信息
- 防撤回
- 系统通知
- 创建共存版
- 开放无障碍访问
- 开放远控环境兼容
- 自定义提示音

## 用法
[前往发行版](https://github.com/zetaloop/BetterWX/releases)下载并运行 `betterwx`，选择版本启用需要的功能。

## 构建

```sh
cargo build --release
```
